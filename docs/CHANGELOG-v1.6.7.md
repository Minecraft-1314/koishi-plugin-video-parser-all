# koishi-plugin-video-parser-all v1.6.7

## 更新日志

### 新增

- 即梦（jimeng）新增专属解析接口：`https://api-new.ifphp.com/api/jimeng`。即梦/剪映（AI 视频/图片）链接默认使用专属接口解析，失败时自动回退主接口。
- 新增插件 API 解析地址文档 [docs/API_ADDRESSES.md](API_ADDRESSES.md)：集中列出主 API 与各平台专属解析接口、请求方式、调用顺序与配置覆盖方法。

### 修复

- 修复点赞/评论/收藏/转发/播放等统计字段无法从 `extra.statistics` 读取的问题：抖音、即梦等接口将统计信息嵌套在 `data.extra.statistics` 下，此前该位置的数值（如点赞数、播放数）会解析为 0。
- 修复图片地址规范化不一致的问题：统一处理 `HTTPS://` 大写协议、`//` 开头的协议相对地址以及对象/数组形式的图片字段，避免生成 `https:HTTPS://...` 之类的错误链接。
- 修复音乐地址为占位垃圾值（如即梦接口返回的 `map[]`）时被当作有效链接发送的问题，现会自动过滤此类无效地址。
- 修复解析时长浮点数未取整的问题（如 `80.01` 秒），现在时长统一为整数秒。
- 修复合并转发发送失败降级为逐条发送时读取不到消息内容的问题（消息内容现随节点一并保存）。
- 修复链接识别相关问题：多链接消息现在按正文出现顺序排列；自动剔除链接后残留的 XML/HTML 标签片段；支持剥离链接尾随的 `.`、`)`、`）` 等中英文标点。

### 配置

- `customApis` 平台下拉新增 `jimeng`（即梦/剪映），支持对即梦专属接口进行自定义覆盖。

### 兼容性

- 增强统计字段解析：同时兼容统计信息位于 `data.statistics` 与 `data.extra.statistics` 两种返回结构。

# koishi-plugin-video-parser-all v1.7.7

由于更新时间较短，故包含 v1.6.6 更新日志

## 更新日志

### 新增

- 音乐链接改为「发送音乐链接」+「发送范围」+「音乐链接是否以语音形式发送（关闭则只发送链接）」三个配置，发送范围可选全部、仅视频、仅图文，默认全部。
- 新增 7 个合并转发开关（`forwardMergeText` / `forwardMergeImage` / `forwardMergeCover` / `forwardMergeAvatar` / `forwardMergeMusicCover` / `forwardMergeVideo` / `forwardMergeMusic`），默认只合并文字、封面、作者头像、作品图片和音乐封面，视频与音乐单独发送。合并段里只剩一条时直接发送，不再额外套一层合并转发。
- 新增 `showVideo`：视频也有了一级开关「发送视频」，与「视频是否以视频形式发送」组成和音乐链接一致的开关组合。
- 新增 `showMusicCoverText` 和 `musicCoverText`：音乐封面可以带文字提示，不再是一张没有说明的图片。
- 调试日志扩展到全链路：配置快照、链接识别、平台配置、API 调用顺序与每次请求耗时、响应码、解析字段摘要、发送计划、分段决策和每次发送结果，敏感值一律打码。只记录命中链接的消息元数据，不记录聊天正文。

### 修复

- 修复合并转发里「作者头像：」「封面：」「音乐封面：」提示文字与正文黏在同一行的问题：提示文字独立成条，图片前补一个换行。
- 修复音乐封面与封面、作者头像重复时同一张图发多次的问题。
- 修复全局 API Key 会随默认请求头发给第三方自定义接口的问题，现在只有对应接口才会带上自己的 Key。
- 修复消息处理或指令执行抛错时缺少兜底日志的问题。

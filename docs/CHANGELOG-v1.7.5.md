# koishi-plugin-video-parser-all v1.7.5

## 更新日志

### 新增

- 新增 Dola 视频链接识别、平台开关和专属解析 API。
- 新增抖音短剧解析接口 `dydj`，抖音调用顺序更新为 `svparse` → `dyjx` → `dydj`。
- 新增抖音 `video_id` 二级原画解析接口 `zjyh`，仅在前序接口返回 `video_id` 但没有媒体地址时调用。

### 修复

- 修复接口返回业务成功但内容为空时不会继续尝试下一接口的问题。
- 修复超时、HTTP 错误和网络失败时的接口回退逻辑。
- 修复自定义平台会额外请求默认主 API 的问题。
- 修复重试次数、重试间隔、请求超时、认证模式、自定义请求头和缓存时间未完整传入解析层的问题。
- 修复消息去重状态不会过期，以及重复内容不提示的问题。
- 修复媒体发送确定失败时不会降级为直链的问题。
- 修复数组下标路径无法解析，以及无效字段映射可能导致异常的问题。

### 优化

- 无明确码率的 `video_backup` 不再覆盖更可靠的主视频链接。
- 源码和构建产物统一移除代码注释。
- 同步更新中英文 README、API 地址文档和链接规则文档。
